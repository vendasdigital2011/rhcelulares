## 3. Diretrizes Inegociáveis para o Desenvolvimento

1. **WhatsApp Cloud API Oficial:** Sob hipótese alguma utilizar bibliotecas de web scraping, emuladores de navegador ou soluções não-oficiais para disparar mensagens. A reputação do número da loja é sagrada.
2. **PostgreSQL Row-Level Security (RLS):** Toda e qualquer tabela que contenha dados de clientes ou transações deve possuir a política de isolamento por `tenant_id` ativada.
3. **Ergonomia Operacional:** O vendedor deve conseguir calcular uma proposta e enviá-la no chat em menos de 45 segundos, e registrar uma venda em menos de 30 segundos.
4. **Resiliência de Webhooks:** O endpoint `/webhooks/meta` deve sempre responder `HTTP 200 OK` em menos de 100ms, delegando o processamento pesado para as filas Redis BullMQ.
